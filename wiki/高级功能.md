## ⏰ 后台调度

> 每周一早上要做什么、每天晚上记得归档什么，全部交给她。

### 三种触发类型

| 类型 | 说明 | 适合 |
|---|---|---|
| 🤖 Agent 任务 | 让某个角色跑一段对话/任务 | 智能体自动处理，如周报生成 |
| 💻 命令脚本 | 执行本地可执行文件（如 node / ps1） | 脚本化操作，如定时构建 |
| 🌐 HTTP 请求 | 对某个 URL 发 GET / POST / PUT… | 调 Webhook、定时抓取 |

### 创建一个调度任务

1. 打开「设置 → 定时与调度」。
2. 点 **新建调度**，填三样东西：
   - **名字**：例如"周一周报提醒"
   - **时间表达式**：`daily 09:00` / `weekly Mon 09:00` / **Cron 五段式（到点就提醒的后台钟表专用时间格式）**
   - **类型**：Agent / 命令 / HTTP，填对应参数
3. 保存后，到了时间她会自动执行，成功/失败都会通知你。

> 💡 **常见 Cron 速查**
> - 每天 9 点：`0 9 * * *`
> - 每周一 9 点：`0 9 * * 1`
> - 每天 23 点归档：`0 23 * * *`
> - 每 6 小时：`0 */6 * * *`

## 🧲 AI 贴靠

> 一边看文档一边和小星对话，一边画图一边让她帮你记要点。

### 3 步贴靠

1. 点顶部「贴靠」按钮（或设置 → 外部 AI 检测）。
2. 她会扫描当前桌面上**可贴靠的 AI 窗口**，列出来。
3. 选一个窗口 → 点"贴靠"。她会自动吸附到目标边上。

### 可调项

| 模式 | 效果 |
|---|---|
| Move 跟随 | 目标窗口移动时，小星跟着挪 |
| Resize 跟随 | 目标窗口变小时，小星一起缩放 |
| Both | 位置 + 大小都跟随 |
| Off | 贴靠完就固定，不再跟随 |

> ✨ **小技巧**：贴靠后如果你对布局不满意，点"重新布局"，她会重新算一版更合适的。

## 🎨 外观设置

> 白天浅色、晚上深色、想要的字体、提醒的节奏，都可以按你的习惯来。

在「设置 → 外观与可读性」调整：

| 类别 | 选项 | 建议 |
|---|---|---|
| **主题** | 多种主题包可选 | 看感觉挑 |
| **可读性预设** | 清晰 / 平衡 / 沉浸 / 高对比 | 长时间用眼选"高对比"；想沉浸选"沉浸" |
| **密度** | 紧凑 / 正常 / 宽松 | 小屏选紧凑，大屏选宽松 |
| **字号** | 滑杆调节 | 默认 100%，不够再加 |
| **通知** | Toast 类型 + 节奏 | 不想被打断就减少"运行完成"提醒 |
| **启动项** | 开机启动 / 启动后隐藏 / 贴靠方式 | 重度用户推荐开机启动 |

## 🔒 安全与权限

> 你的 API Key、对话记录和任务进度，默认都留在本机，不会往外随便跑。

### 我们做了什么

| 措施 | 说明 |
|---|---|
| 🔐 主密码 | 敏感数据以主密码加密后再存磁盘 |
| 🛡 安全存储 | Provider 凭据优先走 `safeStorage`（操作系统级别的保险箱，比单独存文件稳） |
| 🚪 权限边界 | 所有"可能出错"的操作都会走审批弹窗 |
| 👀 遮蔽显示 | 设置里的 Key 默认只露尾巴，长按显示 |
| 📦 脱敏导出 | 导出诊断包前会把敏感字段遮盖 |

### 你可以做什么

- 定期改主密码（设置 → 安全与权限 → 修改主密码）
- 导设置 JSON 前，检查"脱敏导出"勾上了没
- 关掉你暂时不用的远程渠道，减少攻击面
