### 给用户带来什么实际好处

| 之前（V3.8 以前） | 现在（V3.9 自研核心） |
|---|---|
| 依赖 Codex 子进程，异常退出会整段断连 | 核心全在主进程，零外部进程依赖，更稳定 |
| 长对话偶尔 Token 溢出中断 | Context Compactor 自动压缩，永远在窗口内 |
| 工具调用偶发死循环（反复查文件） | Tool Storm Breaker 多维检测 + 熔断 |
| Provider 切换时可能残留旧环境变量 | ProviderConfig 内存直传，纯净无残留 |
| 连接需要写 config.toml + 等子进程 | 直接连接，首连速度提升，少磁盘 I/O |

## 💬 对话陪伴

> 长对话接着聊，上下文不丢。

<div style="padding:18px 22px;border-radius:18px;background:rgba(113,182,255,.10);border:1px solid rgba(113,182,255,.24)">
  <h4>你能做的事</h4>
  <ul>
    <li>发<strong>文字</strong>——正常打字问她。</li>
    <li>发<strong>图片</strong>——拖截图/照片进来，她能看懂画面内容。</li>
    <li>发<strong>语音</strong>——点麦克风说一句，她会先转写再理解。</li>
    <li>让她<strong>朗读</strong>——点回答旁边的 🔈，她读给你听。</li>
    <li>引用某段内容——选中后按"引用"，后续回答会围绕它展开。</li>
  </ul>
</div>

### 常见用法

| 场景 | 怎么说 | 她会怎么做 |
|---|---|---|
| 继续上次没聊完的 | "我们上次聊到哪了？" | 自动定位最近的对话，提醒你到哪里 |
| 让她记住一件事 | "后面我都叫小星好吗" | 会存入会话记忆，以后按你习惯来 |
| 要她只回答不瞎编 | "找不到就说找不到" | 遵守你的限制，避免幻觉式回答 |

## 🧭 任务管理与编排

> 把一件大事拆成几步，做到哪一步存到哪一步。

### 三种模式

<div align="center">
  <table>
    <tbody>
      <tr>
        <td width="33%" valign="top">
          <h3>🧵 主对话模式</h3>
          <sub>最自然。一边聊一边做。</sub>
          <ul>
            <li>边聊天边让她做事</li>
            <li>她会主动提出下一步建议</li>
            <li>适合：灵感型、探索型任务</li>
          </ul>
        </td>
        <td width="33%" valign="top">
          <h3>🧩 Agent Graph</h3>
          <sub>需要多步骤 / 多角色时上它。</sub>
          <ul>
            <li>切换到 Agent Graph 页面</li>
            <li>建任务图：每个节点配一个角色</li>
            <li>保存后执行，按依赖自动流转</li>
          </ul>
        </td>
        <td width="33%" valign="top">
          <h3>✅ Review / Deliver</h3>
          <sub>最后核对交付，避免"假完成"。</sub>
          <ul>
            <li>生成交付审查清单</li>
            <li>核对变更范围、测试、证据</li>
            <li>确认交付摘要和实际一致后，再点交付</li>
          </ul>
        </td>
      </tr>
    </tbody>
  </table>
</div>

### Agent Graph 可用角色

| 角色 | 适合做什么 |
|---|---|
| 代码工程 | 写代码、跑命令、改配置、构建 |
| 界面设计 | 画原型、改 UI、做动效、配主题 |
| 安全审查 | 检查权限边界、密钥泄露、注入风险 |
| 发布交付 | 打包、部署、生成 Release Note |

> ⚠️ **注意**：角色只是让执行时**更聚焦**，不代表可以绕开权限。所有高危操作仍然会等你审批。

### 中断与恢复

- **停止**按钮可随时中断当前执行
- **暂停任务**不会删掉已有的对话/证据
- 重新打开绑定的任务 → 继续原上下文
- Provider 临时断开 → 先恢复连接，再重试未完成操作

> 一键切换整体界面，从聊天氛围到工作台风格，**所有功能按键全部保留**，只是换个心情陪你。

| 场景 | 视觉风格 | 最适合什么时候 |
|---|---|---|
| 💫 **陪伴 (cozy)** | 小星立绘 + 星光 halo + 礼物/星标工具栏 | 想和她聊聊天、吐槽、分享日常 |
| 🧩 **工作台 (workbench)** | 网格科技风 + 任务图快捷入口 + Hero Agent 卡 | 需要写代码、跑命令、用 Agent Graph 做事 |
| 🌙 **专注 (focus)** | 暗调径向渐变 + 聚焦 Vignette，极简结构 | 屏蔽干扰，完成当下这一件事 |

### 四档情绪 Mood（仅陪伴场景）

| 情绪 | 她是什么状态 | 会看到什么 |
|---|---|---|
| 💫 默认 | 温柔陪伴，随时在线 | 经典小星问候 + 送你一颗星 / 抱抱你 |

## 📱 远程继续

> 电脑聊到一半 → 手机继续 → 电脑再继续，同一件事不用搬三次家。

### 渠道对应表

| 渠道 | 入口在哪里 | 适合 |
|---|---|---|
| 微信 | 设置 → 远程对话 → 微信二维码扫码登录 | 日常随手一句、在外快速处理 |
| 手机网页 | 设置 → 远程对话 → 移动服务（Mobile Server）二维码 | 需要发长文本 / 图片 / 文件 |
| Telegram | 设置 → 远程对话 → Telegram Token 填入 | 重度 Telegram 用户 |
| 飞书 | 设置 → 远程对话 → 飞书应用凭据 | 团队协作、多人场景 |

### 使用流程

1. 在桌面端「设置 → 远程对话」打开你要的渠道。
2. 按渠道提示完成配置（扫码 / 填 Token）。
3. 在手机端发一句话给她——桌面端会收到同一条，你自己不会混乱。
4. 回到桌面端继续，所有记录都已同步。

> 🛡 **权限边界**：远程渠道只是"入口"，真正的执行还在你的桌面端上。远程端不会主动保存你的对话副本。
