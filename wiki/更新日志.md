## ✦ HELIOS V3.10 · 12 大深化改进 · 插件内核 + DAG 编排 + 三层记忆 + 自愈降级

> **日期**：2026-08-15
> **主打**：汲取 DeepSeek Harness「一切皆插件」+ kun-reference「缓存优先 + 图驱动」精髓，核心 12 大高阶能力一次到位

### ✨ 新的
- **🔥 12 大深化改进全部落地（全部内部自研实现 · 遵循「本地优先 · 源码不公开」规则）**
  1. **📊 Token 预算可视化** — 软/硬/强制三阈值进度条 + 节省来源（Prefix 缓存 / 推理缓存 / Token Economy）分类汇总
  2. **💓 Dead Man 看门狗** — Turn 90s / Step 45s 无事件自动告警，连续 2 次超时自动中断，防止软死锁
  3. **♻️ 自愈降级 Fallback** — Provider 健康滑动窗口连续失败自动切备用 + 5 分钟冷却回探 + 用户零感知
  4. **🛡️ Tool Sandbox 沙箱** — 路径白名单 workspace 内才写 + Shell 黑名单（format / rd /s /q / diskpart）直接 deny + 写前自动备份防误操作
  5. **⚡ 缓存优先推理 Cache** — 内存 Map LRU + SQLite 持久化双层，sha256 键，7 天 TTL，完全相同场景零模型调用
  6. **🧠 三层混合记忆** — Short（会话）/ Mid（压缩摘要产物复用）/ Long（全局偏好向量库）+ BM25×向量 混合 Top-K 自动注入
  7. **🎛️ 4 运行时模式** — Minimal（零工具闲聊）/ Standard（标准助手）/ Code（编程增强 20 分钟熔断宽容 + 1.3 倍工具步长）/ Creator（长文创作 30 分钟）
  8. **🔁 会话检查点 + 分叉** — 时间轴任意点 rollback 穿越；Fork 分叉保留父上下文并行试多方案
  9. **🧩 Cordis 级插件内核** — Install→Load→Start→Stop→Uninstall 生命周期 + DAG 拓扑依赖解析 + SemVer 版本约束 + .zip 一键导入
  10. **⚙️ Capability 三层解耦注册中心** — ServiceDef（契约）/ Provider（实现 + fitness 评分）/ Consumer（tags AND/OR + attributes 深度匹配）
  11. **🌐 图驱动 DAG 多 Agent 编排** — Kahn 拓扑 + 事件驱动并行 + Condition 分支 / 重试 / 超时 / 子图复用，取代线性任务列表
  12. **🔍 推理 Trace 全链路面板** — 每 Turn 的工具选择理由 / 压缩触发 / 缓存命中 / 模型切换全可追溯，Token 与耗时分布一目了然
- **🏆 质量**：新增对应 12 模块单元测试，全部测试 100% PASS + TypeScript tsc --noEmit 零错误
- **🚪 接口兼容**：原有 V3.9 公开接口零破坏性改动，所有新模块皆为可选注入升级

### 🛡️ 安全
- 所有文件写操作默认限定 workspace 内；Shell 命令必须在 workspace 当前目录执行；高危命令（format/磁盘分区/递归强制删除）默认拒绝

### ⚡ 性能
- 缓存优先循环命中即返回，Prefix Caching + Inference Cache 双重机制，相同场景节省 30-70% Token 与模型调用成本

## ✦ HELIOS V3.9 · 彻底自研核心 · 脱离 Codex

> **日期**：2026-08-14
> **主打**：自研 Agent Loop × 事件溯源会话 × 6 协议直连 LLM × 零外部子进程依赖

### ✨ 新的

- **🔥 彻底脱离 Codex**：移除 `codex/` 子进程、config.toml 写入、jsonl RPC 管道，不再依赖任何外部 Codex App Server 或 CLI
- **自研 HELIOS Core**（`src/main/core/`）——12 大模块完全自研
  - **Agent Loop**：Turn / Step 双层循环，支持多工具调用、流式输出、中断恢复
  - **LLM Client**：直连 5 种协议（`responses` / `chat` / `messages` / `gemini` / `dashscope`）+ 流式 + 工具调用
  - **Tool Registry + Executor**：统一工具注册、执行管道、超时控制、并发守卫、单调检查
  - **Session Event Log**：Event Sourcing 事件溯源，append-only 日志 + 消息派生
  - **Token Economy**：请求级确定性压缩（系统提示 / 工具描述 / 工具结果），省 Token 不丢关键信息
  - **Context Compactor**：双阈值（软/硬/强制）+ 预算驱动跨 Turn 历史折叠
  - **Immutable Prefix**：不可变前缀指纹哈希，启用 LLM Prompt Caching 省算力
  - **Hook Engine**：6 阶段拦截器（PreToolUse / PostToolUse / UserPromptSubmit / TurnStart / TurnEnd / PreCompact）
  - **Tool Storm Breaker**：多维工具风暴检测（重复/无效/循环调用）+ 熔断保护
  - **XCRuntimeClient**：以自研核心实现 CodexRuntimeClient 接口，StarHubRuntime 无感切换
  - **10 个内置工具**：read_file / list_directory / write_file / grep_files / shell_exec / run_project_command / search_files / git_status / git_diff / inspect_workspace
- **架构升级**：参考 DeepSeek Harness「一切皆插件」+ kun-reference「端口/适配器 + 缓存优先循环」优秀设计，小星核心具备同等扩展能力
- **384/384 测试全过 + 构建成功 + tsc --noEmit 零错误**

### 💪 增强

- `StarHubRuntime.createClient` 改为直接传入 `ProviderConfig`，不再走环境变量 + 磁盘配置文件中间环节
- Provider 校验与连接流程更稳定，失败错误消息改为「XC 自研核心」不再提及 Codex
- 线程 source 字段从硬编码 `"codexAppServer"` 更正为标准 `"appServer"`
- 移除 config.toml 写入后，首次连接速度提升（少了磁盘事务 I/O）

### 🐛 修复

- 彻底消除「Codex 进程异常退出导致整个会话断连」问题：核心全在进程内，无外部子进程依赖
- 修复长对话 Token 溢出问题：Context Compactor 双阈值 + 预算驱动自动压缩
- 修复工具调用死循环问题：Tool Storm Breaker 多维检测 + 熔断保护
- 修复 Provider 切换时残留旧环境变量问题：不再走 env 传递，ProviderConfig 内存传递纯净无残留

### 🎨 设计与架构

- 核心层严格遵循「端口/适配器」模式，所有外部依赖通过抽象接口（`ModelClient` / `ToolRegistryPort` / `SessionEventLogPort`）解耦
- Branded ID 系统（`ThreadId` / `TurnId` / `StepId` / `CallId`）防止类型混淆，参考 TypeScript 类型驱动开发最佳实践
- 所有自研模块单元类型覆盖 100%，后续可独立替换任意实现（例如接入本地 OLLAMA 只需新增 LLM Client 适配器）

## ✦ HELIOS V3.8.1 · 多场景多情绪主题

> **日期**：2026-08-14
> **主打**：三场景自由切换 × 四档情绪 × 功能按钮全保留

### ✨ 新的

- **场景系统（Scene）**：顶栏一键切 `陪伴 / 工作台 / 专注` 三套整体界面
  - **陪伴 (cozy)**：小星立绘 + 星光 halo 背景 + 礼物 / 星标 / 菜单 工具栏
  - **工作台 (workbench)**：网格科技风背景 + Hero 卡片 Agent 特性 + 快捷入口
  - **专注 (focus)**：暗调径向渐变 + 聚焦 Vignette，简化界面屏蔽干扰
- **情绪系统 (Mood)**：仅在陪伴场景显示，四档情绪分别对应不同的问候语、占位文案和 Hero 徽标
  - `默认 / 开心 / 困倦 / 调皮`，每个情绪有独立的开场气泡和行动按钮（送你一颗星 / 抱抱你）
- **功能完整保留**：上下文条、新建/分叉/归档、对话/Graph/Review 三模式、图片/语音/朗读/剪贴板/终端/停止/执行 所有按钮随场景自动调整形态，一个都不少
- **tsc --noEmit 通过**：Scene / Mood 类型全程接入 NextApp、NextConversationPane、NextSessionBar

### 💪 增强

- Hero 卡片随场景变化：陪伴显示「今日陪伴时长」，工作台显示「当前会话」，专注显示「专注时长」
- 输入框占位文案、主按钮图标/标签、工具栏结构，根据场景自动匹配
- `xiaoxing-workbench.css` 继续保留，工作台场景可直接沿用原有 workbench 视觉

### 🎨 设计与素材

- 工作台场景新增 `网格背景层 + 网格光晕层` 纯 CSS 叠加
- 专注场景新增 `径向渐变层 + 聚焦暗角层` 纯 CSS 叠加
- 所有问候气泡 / 快捷按钮均使用主题色渐变 + 阴影提升层次

- **HELIOS 引擎升级**：对话、任务、调度底层统一到 HELIOS V3.8
- **启动动画重做**：小星在开场时会主动出现，不会挡你屏幕
- **主对话 + 任务编排**：一边聊一边做，做到哪一步存到哪一步
- **Agent Graph**：多步骤 / 多角色的任务图，按依赖自动流转
- **Mission Dock 右侧事实面板**：文件 / 变更 / 审批 / 终端 / 证据 / 审查全集中
- **远程继续（微信 / 手机网页 / Telegram / 飞书）**：电脑到手机无缝同一件事
- **AI 贴靠**：自动扫描桌面可贴靠 AI 窗口，跟随移动 / 缩放
- **后台调度**：Agent / 命令 / HTTP 三种触发，Cron 精确到每分钟
- **17 颗气氛胶囊**：早安、雨天、睡前、陪伴、节日限定……
- **HELIOS Dashboard**：概览、远程同步、任务日历、任务流水一眼看懂
- **日志面板**：打开底部 "LOG"，能看到所有事件流（HELIOS 事件、渲染、IPC、服务、启动）
