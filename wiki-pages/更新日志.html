✨ 新的

  2. 🔏 Immutable Prefix 前缀指纹 — System/Tools/Pinned/FewShots 合成 SHA256，配合厂商 Prefix Caching 省 30-70% 前缀 Token
  3. 🧩 Compaction Marker 压缩标记 — 压缩产物注入 <kun:tool_digest sha256> XML 标记 + 保留 sourceDigest + sourceItemIds，用户可溯源不做黑箱
  4. 🩹 History Healing 历史自愈 — 加载老会话：抛畸形、补 id、配对 orphan 工具调用/结果，老版本脏数据不再打不开
  5. 🚦 Steering Queue 插嘴转向队列 — 推理中途用户新消息进缓冲队列，安全边界（模型返回完 / 工具结束）自动 drain 注入，纠正不用等整轮结束
  6. 🧑‍💻 PTC 程序化工具调用（DeepSeek Harness 首创 Code Mode） — 多轮 read→grep→批量 edit 合成一段 TS/Python，受控沙箱一次跑完，模型轮次砍 50-80%
  • 💎 第二层 · 可靠性 + 生命周期（P1 7 项）

  2. 📋 Plan Mode 先调研再动手 — 宿主强约束只给读工具（write/edit/bash 一律拦），先写 Markdown 计划用户批准，再切执行模式，防乱改
  3. 🏷️ 自动标题 + 会话摘要（便宜小模型 3 级回退） — roleModel → smallModel → 主模型，超时静默，会话列表不再全是「新建对话」
  4. 🛡️ Atomic JSON 原子写入 + 乐观 CAS + 串行队列 — 同 key 排队写、revision 冲突自动重试 N 次、tmp → rename 原子落盘，断电/并发写不丢文件
  5. 🔒 Data Mutex 跨进程租约互斥 — holderId + TTL(3s renew)，dev 和 prod 两个 runtime 同写一个共享 key 不互相覆盖
  6. 🚀 InflightTracker 飞行请求追踪 — begin/end 配对、run\ try/finally 强制清理、abortAll 一键取消不泄漏
  7. 🪵 ExtensionLogWriter 每个插件独立日志 — 大小滚动(默认 2MB×5 份)+ N 天保留，等级 DEBUG/INFO/WARN/ERROR，插件 bug 直接附日志
  • ⭐ 第三层 · Agent 高阶能力（DeepSeek Harness 独有 4 项）

  2. 🧵 JobsManager 后台作业队列 — 长任务（百张图、批量视频）异步跑，并发度默认 2，maxAttempts 自动重试，pause/resume/cancel 四状态，随时看进度
  3. ⚡ ReasoningEffort 推理努力度场景化策略 — 标题/摘要/闲聊/标准助手/代码创作/长文创作 6 场景，effort + temperature + maxTokens + 模型档位 4 变量下发，省钱又出对
